# 辅助训练片段与 NatV 划分的序列比较

2026-11-04，使用本地实际训练输入与原始序列，检查 2,395 条辅助训练片段。输入 SHA256 与辅助训练记录一致；本次没有训练模型或计算测试集预测分数。

## 原始数据与测试序列

原始 `stage3_accepted_sequences.fasta` 含 13,972 条非空序列。其中能按序列 SHA256 找回 `test.csv` 的 225 条；`corrected_a_recluster_all_seqs.fasta` 补齐其余 6 条。全部 231 条测试序列已保存为 `recovered_test.fasta`，来源文件、原始 ID、记录序号和序列 SHA256 见 `target_sources.csv`。

第二份原始文件含两个空簇标题；读取时跳过标题，保留随后有序列的记录。原始文件未修改。各来源的读取数量、输入文件 SHA256、代码 SHA256 及命令见 `summary.json`。

## 精确包含与相似片段

精确包含要求完整辅助片段逐字符出现在 NatV 全长序列内。另以 MMseqs2 18.8cc5c 检查局部相似：比对序列一致性至少 50%，覆盖辅助查询片段至少 80%（`--cov-mode 2`），E 值不超过 0.001。没有要求覆盖 NatV 全长的 80%。这是启发式搜索结果，不保证找出所有同源片段。

| NatV 集合 | 序列数 / 组数 | 精确包含：辅助片段 / NatV 序列 / 组 | 相似搜索：辅助片段 / NatV 序列 / 组 | 相似配对数 |
| --- | ---: | ---: | ---: | ---: |
| 训练 | 1,644 / 47 | 0 / 0 / 0 | 12 / 623 / 21 | 642 |
| 验证 | 227 / 44 | 1 / 2 / 1 | 13 / 37 / 12 | 54 |
| 测试 | 231 / 44 | 0 / 0 / 0 | 8 / 25 / 10 | 34 |

相似搜索包含两对精确匹配，不能把两类数量相加。验证和测试相关辅助片段的并集为 19 条。

精确匹配为 `aux:b98462ef…338efd7c` 的完整 124 aa，位于两条验证蛋白的第 10–133 位，两者同属 `0224c34d…057b702`。它们的 NMNAT 注释区间为 8–189，共 182 aa；片段仅覆盖长域的 68.13%，因此原来双向 80% 覆盖规则可能遗漏这种完整包含关系。该辅助片段还与同组另外 7 条验证序列达到至少 95% 一致性。

测试集匹配的一致性为 50.0%–56.8%，未发现完整辅助片段的精确包含。**这些是同源相似关系，不能说成 25 条测试序列被精确复制进训练。** 但它们说明：组 ID 不相交，不能代替以辅助片段为长度单位的序列比较。后续数据划分应明确采用哪一种相似性和覆盖规则，而不能直接沿用“已经隔离”的表述。

## 原验证结果的敏感性分析

从已有逐组评分删除发生精确包含的整个组，保留原模型参数、选定权重、三个训练种子和统计方法（2,000 次组 bootstrap，随机种子 8802）：

| 验证范围 | NMNAT ΔNLL：辅助 − 随机，nats/目标残基 | 95% 组区间 | 三种子平均差值为负的组 |
| --- | ---: | --- | ---: |
| 原 44 组、227 条序列 | −0.04900 | [−0.06025, −0.03758] | 42/44 |
| 剔除该组后 43 组、209 条序列 | −0.04840 | [−0.05962, −0.03712] | 41/43 |

去掉该组评分后，其余 43 组仍有负向平均差值。但模型已经使用过相关片段，验证集也参与权重选择；此结果不能称为排除重叠后重新训练的结果。上表没有删除其余仅满足相似搜索条件的组。

## 复算

仓库根目录执行 `natvqvae fragment-overlap --config config/fragment_overlap.yaml`。重算时将配置的 `output` 改为 `data/results/preprocessing/` 下新的空目录，原始文件路径按实际位置调整。配置中的两个外部 FASTA 是原始输入；程序以序列 SHA256 恢复身份，不把 SHA 当作数据库 accession。

逐对结果见 `exact_hits.csv`、`similarity_hits.csv`；后者原始搜索输出见 `similarity_hits.tsv`。`validation_diagnostic.json` 保存统计定义与精确数值。此次输出不改变原划分、权重或已有候选。
