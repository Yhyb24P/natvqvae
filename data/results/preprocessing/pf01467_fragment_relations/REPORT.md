# 辅助片段与 NatV 数据的关系

本次比较使用原辅助训练和验证中的全部 4,079 条片段，以及 NatV 训练 1,644、验证 227、测试 231 条完整序列。测试序列从本地原始数据按序列 SHA256 恢复，只检查序列关系，没有计算预测分数。

以原 domain_cluster50 分组、片段精确包含关系，以及局部比对的 50% identity、较短片段至少 80% 覆盖、E≤0.001 建立片段间连接。凡与 NatV 验证或测试序列有符合条件的匹配，排除该片段所在的整个连通组。NatV 训练序列的匹配单独记录，不作为排除条件。MMseqs2 是启发式搜索，这些规则不能排除所有更远缘的同源关系。

结果保留 **1,437 条片段**，排除 **2,642 条**。被排除者中，81 条直接匹配验证或测试序列，另 2,561 条通过其他辅助片段相连；不能把后者全部称为重复序列。具体匹配与连接路径见 `auxiliary_membership.csv`、`auxiliary_group_forest.csv` 及比对表。

保留片段分属 32 个新连通组和 78 个原分组。最大新组有 1,357 条，因此新连通组只用于排除相关序列，不据此计算训练权重。旧训练与验证权重分别归一化，不能直接合并使用。

保留片段长度为 26–269 aa，中位 197 aa；可对应到 KVP40 的 WT 位点为 10–160 个，中位 65 个。1,432 条标为 local_core，5 条为 full_context_mapping，这些名称不表示功能经过实验验证。仅凭数量不能认定所有片段都适合新的预训练比较，仍需检查它们与自身训练片段能否组成可比任务。

`retained_aux_domains.fasta`、`retained_aux_masks.json` 与 `retained_auxiliary.csv` 保存这个候选语料集合，尚未建立新的辅助训练/验证划分。它不同于原 2,395 条辅助训练输入；后续计算不能称为原研究简单去重后的复现。

复算命令：

```bash
python -m natvqvae.cli fragment-overlap --config config/pf01467_fragment_relations.yaml
```

输出目录已存在时命令拒绝覆盖。`summary.json` 保存原始输入、实现、版本、命令及结果文件的 SHA256。原 44/43 组差值仅是旧权重下的诊断，不是重训练结果。
