## 结构结果

- 置信度：候选 pLDDT 中位 0.914–0.925，pTM 0.902–0.913；WT 0.922/0.913。
- 同一候选 3 个样本自身全长 RMSD 中位：WT 1.04 Å；候选 0.72–1.48 Å。修正 MSA 后样本离散明显低于错误批次，但 3 个样本仍只作描述，不能称为收敛。

候选叠合到 2QJT 的 B 位点中位距离：E248 到另一链约 10.1–10.5 Å、到配体约 2.5–2.8 Å；D308 到另一链约 10.5–13.4 Å、到配体约 3.2–4.1 Å。A+B 与 A/B/WT 的差异很小；这只说明模板邻近性，不是 KVP40 实际几何、活性或稳定性。

## A 类设计依据：事实、假说与可区分结果

A1/A2/A3 是 QVAE 生成的完整多编辑组合；多编辑本身不是设计缺陷，它只限制单点归因，完整组合仍是可研究的对象。下表把已有可追溯信息、当前假说、竞争解释和能区分它们的功能结果分开；没有一项构成接触验证、活性证据或候选排序。距离来自 1F9A/1NUS/2QJO 接触向 WT 的 TMalign/Kabsch 刚性迁移（`../natv_nmnat_state_mapping/variant_selection.csv`），不是 KVP40 实验复合物。

### 各编辑的来源观察与生成行为

来源列取自归档的 PF01467 事件表：只统计 `aux_eligible` 的来源记录（局部比对映射到 KVP40 WT 位点，identity ≥30%、覆盖 ≥80% 或局部核心判据），某位点取目标残基即计一条事件，簇数按 `domain_cluster50` 去重，事件表只保留 ≥2 簇的事件；NMNAT EC 列为这些事件记录中带 NMNAT EC 2.7.7.1 注释（含 dual EC）的子集。事件类型按现役训练集判定：该位点有稳定映射的训练记录数见括号第二项，其中取该残基的记录数见第一项；new 表示该位有稳定映射、但这些映射记录里没有该替换（只限该位被映射到的训练子集，不等于自然界未出现该替换）。

生成列取自 6 个迁移运行（random 与 auxinit 各 3 个 seed，各 3,072 条，共 18,432 条提案，未去重；48 个掩码集在 6 个 run 间相同），逐位点统计被掩蔽的提案数、其中采到非 WT 残基的提案数，以及目标残基的出现次数。掩码位置在 `masks.json` 中按 0-based 存储，比较时必须 +1；按 +1 对齐后，全部 245,303 条编辑都落在其所属组的掩码位置内（掩码外为 0；各 run 编辑数 auxinit 40,032/40,722/41,010，random 40,664/41,806/41,069），即该池只改动被掩蔽位点。本节所有分母均按 +1 对齐统计；该池是掩码条件生成，输出不是先验估计。

## 结论与边界

1. 36 个正式单体结构均与设计序列一致；A+B 的域骨架与 NMNAT 锚点邻域未显示超出父本样本离散的明显变化。单链预测和同源模板叠合不足以排除实际组装风险。
2. B1/B2 是 E→Q/D→N 去电荷假说；结构只显示它们在模板中邻近 AMP/金属，不能证明水解下降。A 的多编辑组合不能单归因于 L18I/T22Q/A134G。A 类可追溯依据、竞争解释和可区分功能结果见上表；L18I/A134G 的 motif 邻近未被证明有利，T22Q 不是直接催化基序编辑，其他编辑也不能一概贬为无演化依据的 QVAE-only。
3. 同源 Nudix 的 B 位点不在实验二聚体界面上，但 Nudix 口袋整体涉及另一亚基；KVP40 组装未知，不能用单体预测或模板距离替代实验。
4. 3 个 diffusion 样本只作描述；无配体结合预测、MD、对接或亲和力排名。所有活性、稳定性、kcat/Km、NAD⁺ 净积累仍 UNKNOWN。
5. 若进入功能实验，WT/A/B/A+B 在同一缓冲和底物条件下的 vNMNAT、vNudix、vnet 时间曲线及目标时间 NAD⁺ 产量是可区分上表假说的结果类型；不能用各自最适条件速率相减。这不是自动的单突变库要求，也不构成候选排序。当前首要工作是按上表复核设计依据，而不是新增结构预测或活性评分。

## 复现

- 输入：`data/results/generation/natv_dual_domain_design/` 的 `candidates.fasta/csv`、`design.json` 与唯一 `source_msa_WT_512.a3m` 副本；12 份 A3M/YAML 可由 `design-build` 从这些输入重建，不提交重复副本。
- 结构：已提交 36 个 `.cif.gz`，命名 `<name>_<原model文件名>.cif.gz`；解压到 `<name>/boltz_results_<name>/predictions/<name>/<原model文件名>` 即可由 `design-summarize` 复算。36 份 `confidence_*.json` 已按原预测目录提交，不需要 GPU。汇总为 `structure_summary.json`、`structure_pairs.csv`、`boltz_run_summary.json`、`boltz_runs.jsonl`。
- 重建 12 个输入时，用一份 config 副本把 `msa_source` 指向 `source_msa_WT_512.a3m` 后运行 `design-build`；不修改历史 `design.json`/config SHA。
