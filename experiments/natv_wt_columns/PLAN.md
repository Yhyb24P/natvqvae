# WT 对齐列生成比较

以公开 KVP40 WT 的冻结 ESM-2 表示为共同条件，学习 341 个对齐列的分布。输入沿用正式训练与验证角色；插入保留在来源映射中，不进入解码输出。gap 是第 21 个可生成类别，unknown 不作监督目标。完整采样每一列，不限制替换数、不按已知位点强行恢复 WT。

QVAE 直接复用已核对的旧 `SequenceGenerator`，随机初始化训练。无潜变量对照保留相同模块、参数数目与解码器，编码输入固定为 WT，经过确定性的 context 投影后解码，独立训练；不读取目标序列，不采样潜变量，不加 KL。二者生成时只接收共同 WT 条件。对照保留同样的模块计算量，以区分随机潜变量及后验训练带来的整体效果；它不等价于历史读取待恢复序列的 SE 去噪器。

每个正式训练组分抽样质量相同，组内均匀；配对模型每步读取同一批记录和同一份掩码。QVAE 使用旧实现的全已知列重构与 categorical KL，对照使用相同的全已知列交叉熵。配对种子、优化器、学习率、batch、温度、epoch 上限及停止规则见 `plan.json`。参数数目、实际步数和计算时间分别记录，不把训练目标差异隐藏为纯离散化效应。

各模型按验证组分等权的每已知列负 ELBO 选择 checkpoint；对照该量为精确交叉熵。两种量仅用于各自模型选择，不作为生成优劣结论。两个配对模型都连续无改善且达到最短训练轮数后一起停止，以保持相同更新步数。

冻结 checkpoint 后，每个模型种子进行 1,024 次原始采样，每次先抽先验 z（对照无此步骤），再按相同温度逐列采样 21 类。gap、重复、来源精确匹配和不合格序列均保留在尝试分母；原始对齐字符串与去 gap 序列分别保存，不把输出的所有对齐列都称作全长可用酶。

主要分布比较为验证集组分等权的 Hamming kernel MMD²，使用全部对齐列、gap 和原始提案；带宽在计划中固定。报告配对种子差与组分重采样区间，此外报告多样性、gap/长度、新颖性及候选双结构域 HMM 命中。验证集已有历史暴露，也参与本轮 checkpoint 选择；结果只作开发比较。测试集序列不参与该任务，不据模型分数判断催化活性。

用户已授权本轮训练和生成，计算预算无上限。当前 GPU 被其他进程占用时使用 CPU，不中断其他作业。来源和数据边界见 `../../docs/DATA_PROVENANCE.md`；原实现身份见 `../../discovery/natv_model_inheritance/source_checks.json`。
