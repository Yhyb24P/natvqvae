# NatV 条件 QVAE：联合建模与候选序列供给

采用完整序列后验、学习型条件先验和共享16×8 Categorical潜变量；正式生成仅从条件先验采样。研究定义与预算见 `PLAN.md`，输入身份见 `inputs/`，完整产物身份见 `result_checksums.json`。

完成 38 次拟合，拟合计算累计 3.26 小时。原始逐输入记录、失败、权重与完整候选位于 `data/results/natv_conditional_qvae/raw/` 和 `data/models/natv_conditional_qvae/`。

训练与验证曲线见 `training_curves.png`，27种验证条件分图见 `validation_panel_curves.png`，计量口径见 `curve_definitions.json`。QVAE训练后验重构CE与验证条件边缘NLL不是同一概率量。

完整目标上QVAE相对确定性模型有很小的开发集预测改善；其边缘独立版本同样优于确定性模型，因此不能把全部差异归因于共享z。自身边缘与共享z之差仅约0.00006–0.00007 nats/残基。重复SE和bootstrap不包含有限样本对数估计的共同偏差，微小差值应谨慎解释。

主结论：尚未取得有意义的联合建模优势或候选供给优势的充分证据。成对/三位点的家族混合背景TV改善区间均包含零，许多联合事件支持不足；候选唯一数量与家族HMM证据也基本相当。这不等于证明所有离散潜变量模型均无效。

全部评分来自参与选参的227条开发验证序列，区间以本轮已选配置为条件，不是经过选参校正的独立测试结论；231条测试目标继续封存。训练群体1644条/47组分，开发验证227条/44组分，正式比较5个配对种子；每方法64样本、8次重复，确定性概率精确。逐输入ESS、权重集中及MC误差保存在完整记录中。

配对种子中，共享先验联合NLL在4/5个种子上低于确定性对照，另有1个种子反向。条件先验分布接近均匀、上下文间差异很小，见 `conditional_prior_diagnostics.json`；这只作诊断，不独立证明潜变量是否学习了天然联合规律。

联合概率改善与可靠共变统计改善同时成立才支持联合建模收益；候选数量、KL非零或改变z产生差异均不能单独支持该结论。该计算研究提供后续可检验序列，不证明工程性能改善。


供给比较的匹配样本严格同种子、同掩码、同替换数，差异与匹配损失见摘要。代表清单中的匹配参照只优先相同生成条件，允许同区域/规模、相近替换数的跨种子参照，不能称全部完全同条件。HMM有序双域命中只属于序列profile证据。
