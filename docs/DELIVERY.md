# NatV 蛋白资料

[资料包说明与文件清单](../data/results/evaluation/natv_candidate_delivery/README.md)

资料包包括共同野生型（WT）、11 条设计变体和 NatV10、NatV89 两条易错 PCR 克隆，共 14 条不同的蛋白序列。每条有 3 个预测结构，合计 42 个 PDB；另外保留易错 PCR 研究所用的 3 个 WT 结构，供复算该批比较结果。

完整序列和氨基酸替换见包内 `candidates.csv`、`candidates.fasta`，测序核查与设计来源见 `evidence/`，结构图和 RMSD 结果见 `attachments/`。目前没有经验证的活性排序。
